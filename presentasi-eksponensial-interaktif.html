Bayangkan: satu bakteri berada di piring. Setiap 20 menit bakteri itu membelah diri menjadi 2. Setelah pembelahan, kedua bakteri masing-masing juga membelah 20 menit kemudian — dan seterusnya.

Dari 1 menjadi lebih dari 16 juta hanya dalam 8 jam. Inilah kekuatan eksponensial: tumbuh bukan dengan cara bertambah, tetapi dengan cara dikali.

Materi 0 · Konteks Dunia Nyata

Eksponen di Kehidupan Sehari-hari

Rumus umum pertumbuhan / peluruhan: N(t) = N0 · at
Keterangan: N0 = jumlah awal, a = rasio setiap periode, t = banyaknya periode. Jika a > 1 terjadi pertumbuhan (misal bakteri), jika 0 < a < 1 terjadi peluruhan (misal sisa radioaktif).
🦠

1 · Bakteri & Virus

Bakteri membelah diri menjadi 2 setiap periode, sehingga jumlahnya mengikuti N = N0 · 2n. Inilah alasan infeksi bisa menyebar sangat cepat dalam hitungan jam.

💰

2 · Bunga Majemuk Bank

Tabungan M0 dengan bunga i per tahun selama n tahun menjadi M = M0(1 + i)n. Bunga yang ikut berbunga inilah yang disebut majemuk.

☢️

3 · Peluruhan Radioaktif

Massa unsur radioaktif menyusut menjadi setengah setiap waktu paruh: N = N0 · (1/2)t/T, dengan T waktu paruh. Dipakai untuk penanggalan fosil (karbon-14).

📉

4 · Nilai Aset & Populasi

Harga kendaraan turun sekitar 10% per tahun: V = V0(0,9)n. Sebaliknya, populasi penduduk atau pengguna internet tumbuh mirip pola eksponensial.

Contoh Hitungan Eksponen Sehari-hari

📌 Contoh 1 — Jumlah Bakteri

Sejumlah 100 bakteri diletakkan di piring. Bakteri membelah diri menjadi dua setiap 20 menit. Tentukan banyaknya bakteri setelah 2 jam!

Tentukan panjang periode: 2 jam = 120 menit, tiap periode 20 menit → banyaknya pembelahan n = 120 : 20 = 6.
Susun model: N = N0 · 2n = 100 · 26.
Hitung: 26 = 64, sehingga N = 100 × 64 = 6.400.
Jadi, ada 6.400 bakteri setelah 2 jam.
✓ Uji cepat: 100 → 200 → 400 → 800 → 1.600 → 3.200 → 6.400 (6 kali lipat-2) ✔
📌 Contoh 2 — Bunga Majemuk

Bu Rina menabung Rp2.000.000 di bank dengan bunga majemuk 10% per tahun. Tentukan jumlah tabungan Bu Rina setelah 3 tahun!

Model bunga majemuk: M = M0(1 + i)n dengan M0 = 2.000.000, i = 10% = 0,1, n = 3.
Substitusi: M = 2.000.000 × (1,1)3.
Hitung: (1,1)3 = 1,331, sehingga M = 2.000.000 × 1,331 = 2.662.000.
Tabungan menjadi Rp2.662.000.
✓ Uji tahunan: 2.200.000 → 2.420.000 → 2.662.000 ✔ (bunga ikut berbunga!)
Bonus ☢️: unsur radioaktif 96 gram memiliki waktu paruh 3 jam (setiap 3 jam massanya menjadi setengah). Setelah 12 jam tersisa 96 × (1/2)12/3 = 96 × (1/2)4 = 6 gram. Pola yang sama, hanya saja a < 1 (peluruhan).

Persamaan Eksponensial · Bentuk 1

Bentuk 1: af(x) = ap

Aturan: af(x) = ap ⟺ f(x) = p, dengan syarat a > 0 dan a ≠ 1.
Ubah ruas kanan menjadi pangkat dengan basis yang sama dengan ruas kiri.
Samakan pangkatnya: tulis f(x) = p.
Selesaikan persamaan yang terbentuk (linear atau kuadrat).
📌 Contoh 1

Tentukan nilai x yang memenuhi 32x−1 = 27.

Samakan basis: 27 = 33, sehingga persamaan menjadi 32x−1 = 33.
Samakan pangkat: 2x − 1 = 3.
Selesaikan: 2x = 4 → x = 2.
x = 2
✓ Uji: 32(2)−1 = 33 = 27 ✔
📌 Contoh 2

Tentukan himpunan penyelesaian dari 5x²−2x = 125.

Samakan basis: 125 = 53 → 5x²−2x = 53.
Samakan pangkat: x² − 2x = 3 → x² − 2x − 3 = 0.
Faktorkan: (x − 3)(x + 1) = 0 → x = 3 atau x = −1.
HP = {x | x = 3 atau x = −1}
✓ Uji x=3: 59−6 = 53 ✔  ·  Uji x=−1: 51+2 = 53 ✔
Ingat: pangkat kanan boleh negatif atau pecahan! Misal 1/9 = 3−2 dan 8 = (1/2)−3.

Bentuk 2: af(x) = ag(x)

Aturan: af(x) = ag(x) ⟺ f(x) = g(x), dengan syarat a > 0 dan a ≠ 1. Jika basisnya belum sama, jadikan sama dulu (misal 4 = 22, 9 = 32, 1/8 = 2−3).
📌 Contoh 1

Tentukan nilai x yang memenuhi 2x+2 = 23x−4.

Basisnya sudah sama (2), langsung samakan pangkat: x + 2 = 3x − 4.
Pindahkan semua x ke satu ruas: 2 + 4 = 3x − x → 6 = 2x.
Selesaikan: x = 3.
x = 3
✓ Uji: 25 = 29−4 = 32 ✔
📌 Contoh 2

Tentukan himpunan penyelesaian dari 2x²−3x = 2x+5.

Samakan pangkat: x² − 3x = x + 5.
Susun ke bentuk kuadrat: x² − 4x − 5 = 0.
Faktorkan: (x − 5)(x + 1) = 0 → x = 5 atau x = −1.
HP = {x | x = 5 atau x = −1}
✓ Uji x=5: 210 = 210 ✔  ·  Uji x=−1: 24 = 24 ✔
Hati-hati: bila pangkatnya kuadrat dan diskriminannya negatif (misal x² − 4x + 5 = 0), persamaan tidak memiliki penyelesaian real — jawabannya bukan selalu ada!

Kuis Bentuk 2: af(x) = ag(x)

Pilih satu jawaban, tekan Cek Jawaban, lalu pelajari pembahasannya. Skormu tercatat otomatis ⭐

1Nilai x yang memenuhi 52x−1 = 5x+2 adalah …
💬 Pembahasan 2x − 1 = x + 2 → 2x − x = 2 + 1 → x = 3.
✓ Uji: 55 = 55 ✔
2Nilai x yang memenuhi 42x+3 = 4x+7 adalah …
💬 Pembahasan 2x + 3 = x + 7 → 2x − x = 7 − 3 → x = 4.
✓ Uji: 411 = 411 ✔
3Himpunan penyelesaian 6x²−x = 62x adalah …
💬 Pembahasan x² − x = 2x → x² − 3x = 0 → x(x − 3) = 0 → x = 0 atau x = 3.
✓ Uji x=0: 60 = 60 ✔
4Nilai x yang memenuhi (0,5)x−1 = (0,5)2x+3 adalah …
💬 Pembahasan Basis desimal pun boleh! x − 1 = 2x + 3 → −4 = x → x = −4.
✓ Uji: (0,5)−5 = (0,5)−5 ✔
5Nilai x yang memenuhi 103x+1 = 105x−7 adalah …
💬 Pembahasan 3x + 1 = 5x − 7 → 1 + 7 = 5x − 3x → 8 = 2x → x = 4.
✓ Uji: 1013 = 1013 ✔
Persamaan Eksponensial · Bentuk 3

Bentuk 3: af(x) = bf(x)

Aturan: jika a ≠ b dan keduanya positif, maka af(x) = bf(x) ⟺ f(x) = 0.
Mengapa? Bagi kedua ruas dengan bf(x): (a/b)f(x) = 1. Karena a/b ≠ 1, satu-satunya cara agar hasil pangkatnya 1 adalah pangkatnya nol: f(x) = 0.
📌 Contoh 1

Tentukan nilai x yang memenuhi 5x+2 = 7x+2.

Basis 5 ≠ 7 dengan pangkat sama f(x) = x + 2 → pakai aturan: x + 2 = 0.
Selesaikan: x = −2.
x = −2
✓ Uji: 50 = 1 = 70 ✔
📌 Contoh 2

Tentukan nilai x yang memenuhi 23x−9 = 83x−9.

Sekilas basis beda (2 dan 8), tapi bisa disamakan: 8 = 23 → ruas kanan 83x−9 = 23(3x−9) = 29x−27.
Sekarang basis sama → pangkat sama: 3x − 9 = 9x − 27.
Selesaikan: 18 = 6x → x = 3. (Pintasan: pangkat kiri = pangkat kanan awal, basis 2 ≠ 8 → 3x − 9 = 0 → x = 3.)
x = 3
✓ Uji: 20 = 1 = 80 ✔
Perhatikan: bentuk ini sering "menyamar"! Basis bisa ditulis beda padahal nilainya sama (8 = 23) atau benar-benar beda (5 dan 7). Kenali dulu, baru pilih strategi.

Kuis Bentuk 3: af(x) = bf(x)

Pilih satu jawaban, tekan Cek Jawaban, lalu pelajari pembahasannya. Skormu tercatat otomatis ⭐

1Nilai x yang memenuhi 3x−4 = 6x−4 adalah …
💬 Pembahasan Basis 3 ≠ 6 dan pangkatnya sama → pangkat harus 0: x − 4 = 0 → x = 4.
✓ Uji: 30 = 1 = 60 ✔
2Nilai x yang memenuhi 22x+8 = 42x+8 adalah …
💬 Pembahasan Boleh langsung: basis efektif 2 ≠ 4 → 2x + 8 = 0 → x = −4. Cara panjang: 42x+8 = 24x+16 → 2x + 8 = 4x + 16 → x = −4.
✓ Uji: 20 = 1 = 40 ✔
3Himpunan penyelesaian 5x²−9 = 6x²−9 adalah …
💬 Pembahasan Basis 5 ≠ 6 → x² − 9 = 0 → x² = 9 → x = 3 atau x = −3.
✓ Uji: 50 = 1 = 60 ✔
4Nilai x yang memenuhi 4x−1 = 8x−1 adalah …
💬 Pembahasan Basis 4 ≠ 8 → pangkat nol: x − 1 = 0 → x = 1. Dengan cara samakan basis: 22x−2 = 23x−3 → 2x − 2 = 3x − 3 → x = 1.
✓ Uji: 40 = 1 = 80 ✔
5Nilai x yang memenuhi 73x+6 = (1/7)3x+6 adalah …
💬 Pembahasan Basis 7 ≠ 1/7 (keduanya positif, nilainya beda) dan pangkatnya sama → 3x + 6 = 0 → x = −2.
✓ Uji: 70 = 1 = (1/7)0 ✔

Bentuk 4: f(x)g(x) = f(x)h(x)

Bentuk ini istimewa karena basisnya juga berupa fungsi. Persamaan f(x)g(x) = f(x)h(x) dipenuhi jika salah satu tiga kasus berikut terjadi:
KasusSyaratKeterangan
① Basis = 1f(x) = 11 pangkat berapapun selalu 1 → selalu benar
② Pangkat samag(x) = h(x)Syarat: basisnya bukan 0, yaitu f(x) ≠ 0
③ Basis = 0f(x) = 00k = 0 hanya untuk k > 0 → wajib g(x) > 0 dan h(x) > 0
📌 Contoh 1

Tentukan himpunan penyelesaian (x − 2)x+1 = (x − 2)2x−3.

Kasus ① basis 1: x − 2 = 1 → x = 3.
Kasus ② pangkat sama: x + 1 = 2x − 3 → x = 4 (basisnya 4 ≠ 0, sah).
Kasus ③ basis 0: x − 2 = 0 → x = 2; cek pangkat: x+1 = 3 > 0 dan 2x−3 = 1 > 0 → diterima.
Gabungkan semua kasus yang lolos.
HP = {x | x = 2 atau x = 3 atau x = 4}
✓ Uji: 03 = 01 ✔ · 14 = 13 ✔ · 45 = 45 ✔
📌 Contoh 2

Tentukan himpunan penyelesaian (x + 3)2x−1 = (x + 3)x+2.

Kasus ① basis 1: x + 3 = 1 → x = −2.
Kasus ② pangkat sama: 2x − 1 = x + 2 → x = 3.
Kasus ③ basis 0: x + 3 = 0 → x = −3; cek pangkat: 2x−1 = −7 (negatif!) → ditolak, karena 0−7 tidak terdefinisi.
HP = {x | x = −2 atau x = 3}
✓ Uji: 1−5 = 10 = 1 ✔ · 65 = 65 ✔
Jangan lupa kasus ③! Banyak soal ujian menjebak di sini: jawaban basis 0 harus diuji dulu apakah kedua pangkatnya positif. Jika salah satu negatif atau nol → buang jawaban itu.

Kuis Bentuk 4: f(x)g(x) = f(x)h(x)

Ingat 3 kasus: basis 1, pangkat sama, dan basis 0 (dengan pangkat positif). Pilih jawaban lalu tekan Cek Jawaban ⭐

1Himpunan penyelesaian (x − 1)x+2 = (x − 1)3x−4 adalah …
💬 Pembahasan ① Basis 1: x − 1 = 1 → x = 2.
② Pangkat sama: x + 2 = 3x − 4 → x = 3.
③ Basis 0: x = 1 → pangkat x+2 = 3 > 0 tapi 3x−4 = −1 < 0 → ditolak.
Jadi HP = {2, 3}.
2Himpunan penyelesaian (x + 2)2x = (x + 2)x+1 adalah …
💬 Pembahasan ① Basis 1: x + 2 = 1 → x = −1.
② Pangkat sama: 2x = x + 1 → x = 1.
③ Basis 0: x = −2 → pangkat 2x = −4 < 0 → ditolak.
Jadi HP = {−1, 1}.
3Himpunan penyelesaian (2x − 1)x−3 = (2x − 1)2x−7 adalah …
💬 Pembahasan ① Basis 1: 2x − 1 = 1 → x = 1.
② Pangkat sama: x − 3 = 2x − 7 → x = 4.
③ Basis 0: x = 1/2 → pangkat x−3 = −2,5 < 0 → ditolak.
Jadi HP = {1, 4}.
4Himpunan penyelesaian (3 − x)x+1 = (3 − x)2x−1 adalah …
💬 Pembahasan ① Basis 1: 3 − x = 1 → x = 2.
② Pangkat sama: x + 1 = 2x − 1 → x = 2 (ketemu juga di sini!).
③ Basis 0: x = 3 → pangkat x+1 = 4 > 0 dan 2x−1 = 5 > 0 → diterima!
Jadi HP = {2, 3}. Kali ini kasus ③ lolos uji — selalu cek!
5Himpunan penyelesaian (x² − 4)x−2 = (x² − 4)x+2 adalah …
💬 Pembahasan ① Basis 1: x² − 4 = 1 → x² = 5 → x = ±√5.
② Pangkat sama: x − 2 = x + 2 → mustahil (−4 = 0), tidak ada.
③ Basis 0: x = ±2; untuk x = 2 pangkatnya 0 (tidak > 0) → ditolak; untuk x = −2 pangkatnya −4 < 0 → ditolak.
Jadi HP = {±√5} ≈ {±2,24}.
Persamaan Eksponensial · Bentuk 5

Bentuk 5: A(af(x))2 + B·af(x) + C = 0

Aturan (substitusi): misalkan t = af(x), ingat (af(x))2 = a2f(x). Persamaan berubah menjadi kuadrat biasa: At² + Bt + C = 0.
Setelah nilai t ditemukan, kembalikan ke af(x) = t. Hanya nilai t > 0 yang boleh dipakai — pangkat dari bilangan positif selalu positif!
📌 Contoh 1

Tentukan himpunan penyelesaian 9x − 12·3x + 27 = 0.

Perhatikan 9x = (3²)x = (3x)². Misalkan t = 3x (dengan t > 0): persamaan menjadi t² − 12t + 27 = 0.
Faktorkan: (t − 3)(t − 9) = 0 → t = 3 atau t = 9. Keduanya positif ✔
Kembalikan: 3x = 3 → x = 1; dan 3x = 9 → x = 2.
HP = {x | x = 1 atau x = 2}
✓ Uji x=2: 81 − 108 + 27 = 0 ✔
📌 Contoh 2

Tentukan himpunan penyelesaian 25x − 6·5x + 5 = 0.

Misalkan t = 5x, maka 25x = (5x)² = t²: persamaan menjadi t² − 6t + 5 = 0.
Faktorkan: (t − 1)(t − 5) = 0 → t = 1 atau t = 5. Positif ✔
Kembalikan: 5x = 1 = 50 → x = 0; dan 5x = 5 → x = 1.
HP = {x | x = 0 atau x = 1}
✓ Uji x=1: 25 − 30 + 5 = 0 ✔
Jebakan klasik: jika salah satu akar t bernilai ≤ 0 (misal t = −2), akar itu langsung dibuang, karena af(x) tidak mungkin bernilai nol atau negatif. Jangan lupa memeriksa!
Kuis Interaktif · 5 Soal

Kuis Bentuk 5: Kuadrat dalam af(x)

Misalkan t = af(x), selesaikan kuadratnya, lalu kembalikan. Tekan Cek Jawaban untuk koreksi ⭐

1Himpunan penyelesaian 22x − 6·2x + 8 = 0 adalah …
💬 Pembahasan Misal t = 2x → t² − 6t + 8 = 0 → (t − 2)(t − 4) = 0 → t = 2, 4.
Kembali: 2x = 2 → x = 1; 2x = 4 → x = 2. Jadi HP = {1, 2}.
2Himpunan penyelesaian 32x+1 − 28·3x + 9 = 0 adalah …
💬 Pembahasan Tulis 32x+1 = 3·(3x)². Misal t = 3x → 3t² − 28t + 9 = 0 → (3t − 1)(t − 9) = 0 → t = 1/3 atau t = 9.
Kembali: 3x = 1/3 → x = −1; 3x = 9 → x = 2. Jadi HP = {−1, 2}.
3Himpunan penyelesaian 9x − 4·3x + 3 = 0 adalah …
💬 Pembahasan Misal t = 3x → t² − 4t + 3 = 0 → (t − 1)(t − 3) = 0 → t = 1, 3.
Kembali: 3x = 1 → x = 0; 3x = 3 → x = 1. Jadi HP = {0, 1}.
4Himpunan penyelesaian 52x − 26·5x + 25 = 0 adalah …
💬 Pembahasan Misal t = 5x → t² − 26t + 25 = 0 → (t − 1)(t − 25) = 0 → t = 1, 25.
Kembali: 5x = 1 → x = 0; 5x = 25 = 5² → x = 2. Jadi HP = {0, 2}.
5Himpunan penyelesaian 22x+2 − 33·2x + 8 = 0 adalah …
💬 Pembahasan Tulis 22x+2 = 4·(2x)². Misal t = 2x → 4t² − 33t + 8 = 0 → (4t − 1)(t − 8) = 0 → t = 1/4 atau t = 8.
Kembali: 2x = 1/4 = 2−2 → x = −2; 2x = 8 → x = 3. Jadi HP = {−2, 3}.
Pertidaksamaan Eksponensial · Pengantar

Pertidaksamaan Eksponensial: Aturan Dasar

Pertidaksamaan eksponensial adalah pertidaksamaan yang variabelnya berada di pangkat, contohnya 2x > 8. Persoalan utamanya: apakah tanda pertidaksamaan berubah? Jawabannya bergantung pada nilai basis a:

Kasus a > 1 (fungsi naik ↗, misal 2x):
af(x) > ag(x) ⟺ f(x) > g(x) → tanda TETAP.
Kasus 0 < a < 1 (fungsi turun ↘, misal (1/2)x):
af(x) > ag(x) ⟺ f(x) < g(x) → tanda TERBALIK.
Pastikan basis positif dan tidak sama dengan 1.
Samakan basis kedua ruas (contoh: 8 = 23, 1/9 = (1/3)2).
Cek nilai basisnya: a > 1 → pertahankan tanda; 0 < a < 1 → balikkan tanda.
Selesaikan pertidaksamaan yang terbentuk (linear/kuadrat), lalu tulis himpunan penyelesaiannya.
Trik mengingat: basis kecil (kurang dari 1) itu "nakal" — tanda pertidaksamaannya dibalik. Basis besar (lebih dari 1) itu "rajin" — tanda tetap. 😄
Pertidaksamaan Eksponensial · Kasus 1

Kasus a > 1: Tanda Tetap

Aturan: untuk a > 1, fungsi eksponensial naik, sehingga:
af(x) > ag(x) ⟺ f(x) > g(x)  ·  af(x) < ag(x) ⟺ f(x) < g(x)
Tanda pertidaksamaan tidak berubah. Sifat ini juga berlaku untuk tanda ≥ dan ≤.
📌 Contoh 1

Tentukan himpunan penyelesaian 22x−3 > 8.

Samakan basis: 8 = 23 → 22x−3 > 23.
Basis 2 > 1 → tanda tetap: 2x − 3 > 3.
Selesaikan: 2x > 6 → x > 3.
HP = {x | x > 3, x ∈ ℝ}
✓ Uji x=4: 25 = 32 > 8 ✔ · Uji x=2: 21 = 2 ≤ 8 ✔
📌 Contoh 2

Tentukan himpunan penyelesaian 3x²−4x > 9−x.

Samakan basis: 9−x = 3−2x → 3x²−4x > 3−2x.
Basis 3 > 1 → tanda tetap: x² − 4x > −2x.
Rapikan: x² − 2x > 0 → x(x − 2) > 0.
Titik kritis 0 dan 2; parabola terbuka ke atas, hasil positif di luar kedua akar: x < 0 atau x > 2.
HP = {x | x < 0 atau x > 2, x ∈ ℝ}
✓ Uji x=3 (anggota HP): 3−3 ≈ 0,037 > 9−3 ≈ 0,001 ✔ · Uji x=1 (bukan anggota): 3−3 ≈ 0,037 < 9−1 ≈ 0,111 ✔
Ingat: bila pangkatnya berbentuk kuadrat, gunakan garis bilangan / uji interval seperti menyelesaikan pertidaksamaan kuadrat biasa.
Kuis Interaktif · 5 Soal

Kuis Kasus a > 1

Semua soal berikut memakai basis > 1 → tanda pertidaksamaan tetap. Tekan Cek Jawaban untuk koreksi ⭐

1Himpunan penyelesaian 5x−2 > 25 adalah …
💬 Pembahasan 25 = 52 → 5x−2 > 52. Basis 5 > 1, tanda tetap: x − 2 > 2 → x > 4.
2Himpunan penyelesaian 23x−1 < 32 adalah …
💬 Pembahasan 32 = 25 → 23x−1 < 25. Basis 2 > 1, tanda tetap: 3x − 1 < 5 → 3x < 6 → x < 2.
3Himpunan penyelesaian 42x+1 > 64 adalah …
💬 Pembahasan 64 = 43 → 42x+1 > 43. Basis 4 > 1: 2x + 1 > 3 → 2x > 2 → x > 1.
4Himpunan penyelesaian 3x²−3x < 1 adalah …
💬 Pembahasan 1 = 30 → 3x²−3x < 30. Basis 3 > 1: x² − 3x < 0 → x(x − 3) < 0 → 0 < x < 3.
5Himpunan penyelesaian 2x²−2x−3 ≥ 1 adalah …
💬 Pembahasan 1 = 20 → x² − 2x − 3 ≥ 0 → (x − 3)(x + 1) ≥ 0 → parabola positif di luar akar: x ≤ −1 atau x ≥ 3.
Pertidaksamaan Eksponensial · Kasus 2

Kasus 0 < a < 1: Tanda Berbalik

Aturan: untuk 0 < a < 1, fungsi eksponensial turun, sehingga:
af(x) > ag(x) ⟺ f(x) < g(x)  ·  af(x) < ag(x) ⟺ f(x) > g(x)
Tanda pertidaksamaan berbalik arah! Basis seperti ini: 1/2, 1/3, 1/10, 0,5, 0,25, dan sebagainya.
📌 Contoh 1

Tentukan himpunan penyelesaian (1/2)2x−1 > 8.

Samakan basis: 8 = 23 = (1/2)−3 → (1/2)2x−1 > (1/2)−3.
Basis 1/2 antara 0 dan 1 → tanda dibalik: 2x − 1 < −3.
Selesaikan: 2x < −2 → x < −1.
HP = {x | x < −1, x ∈ ℝ}
✓ Uji x=−2: (1/2)−5 = 32 > 8 ✔ · Uji x=0: (1/2)−1 = 2 ≤ 8 ✔
📌 Contoh 2

Tentukan himpunan penyelesaian (0,5)2x−4 < (0,5)x+1.

Basis sudah sama: 0,5 = 1/2 dengan 0 < 0,5 < 1.
Tanda dibalik: 2x − 4 > x + 1.
Selesaikan: 2x − x > 1 + 4 → x > 5.
HP = {x | x > 5, x ∈ ℝ}
✓ Uji x=6: (0,5)8 < (0,5)7 ✔ (0,58 lebih kecil — pangkat besar pada basis kecil justru makin kecil)
Kesalahan paling sering: lupa membalik tanda pada basis kecil! Selalu tanyakan pada dirimu: "basisnya kurang dari 1?" Jika ya → balik tanda sebelum menyelesaikan.
Kuis Interaktif · 5 Soal

Kuis Kasus 0 < a < 1

Semua basis di bawah kurang dari 1 → tanda pertidaksamaan berbalik. Tekan Cek Jawaban untuk koreksi ⭐

1Himpunan penyelesaian (1/3)x−1 > (1/3)3 adalah …
💬 Pembahasan Basis 1/3 < 1 → tanda dibalik: x − 1 < 3 → x < 4.
2Himpunan penyelesaian (0,5)2x < 8 adalah …
💬 Pembahasan 8 = 23 = (1/2)−3 → (0,5)2x < (0,5)−3. Basis 0,5 < 1 → tanda dibalik: 2x > −3 → x > −3/2.
3Himpunan penyelesaian (1/2)x²−4 > 1 adalah …
💬 Pembahasan 1 = (1/2)0 → basis kecil, tanda dibalik: x² − 4 < 0 → (x−2)(x+2) < 0 → −2 < x < 2.
4Himpunan penyelesaian (0,25)x+2 ≥ (0,25)3x−1 adalah …
💬 Pembahasan 0,25 = 1/4, basis < 1 → tanda dibalik (≥ menjadi ≤): x + 2 ≤ 3x − 1 → 3 ≤ 2x → x ≥ 3/2.
5Himpunan penyelesaian (1/3)x²−3x−10 ≤ 1 adalah …
💬 Pembahasan 1 = (1/3)0 → tanda dibalik: x² − 3x − 10 ≥ 0 → (x − 5)(x + 2) ≥ 0 → x ≤ −2 atau x ≥ 5.
Soal Cerita · Model & Contoh

Soal Cerita Eksponensial

SituasiModelContoh
Pertumbuhan (belah diri, berlipat)N = N0 · an, a > 1Bakteri, virus, penduduk
Peluruhan (menyusut)N = N0 · an, 0 < a < 1Radioaktif, nilai kendaraan
Bunga majemukM = M0(1 + i)nTabungan di bank
Tentukan N0 (jumlah awal) dan rasio perubahan per periode (a).
Hitung banyaknya periode n — samakan satuan waktu (menit ↔ jam, hari, tahun)!
Susun model dan substitusikan nilai yang diketahui.
Hitung nilai yang ditanya; untuk soal mencari waktu, selesaikan persamaan eksponensialnya.
📌 Contoh 1 — Pertumbuhan Bakteri

Sebuah laboratorium menumbuhkan 100 bakteri. Setiap 20 menit, jumlah bakteri menjadi dua kali sebelumnya. Berapa banyak bakteri setelah 2 jam?

Diketahui: N0 = 100, rasio a = 2 tiap 20 menit.
Banyak periode: 2 jam = 120 menit → n = 120 : 20 = 6.
Model: N = 100 · 26 = 100 × 64 = 6.400.
Ada 6.400 bakteri setelah 2 jam.
📌 Contoh 2 — Peluruhan Radioaktif

Massa awal sebuah unsur radioaktif adalah 96 gram. Unsur ini meluruh menjadi setengahnya setiap 3 jam. Berapa massa unsur yang tersisa setelah 12 jam?

Diketahui: N0 = 96, waktu paruh 3 jam → rasio a = 1/2 per 3 jam.
Banyak periode: n = 12 : 3 = 4 kali peluruhan.
Model: N = 96 · (1/2)4 = 96 × 1/16 = 6 gram.
Tersisa 6 gram setelah 12 jam.
Kuis Interaktif · 5 Soal

Kuis Soal Cerita Eksponensial

Identifikasi N₀, rasio, dan banyaknya periode dengan teliti (hati-hati satuan waktu!). Tekan Cek Jawaban untuk koreksi ⭐

1Sejumlah 50 bakteri berkembang biak dengan cara membelah diri menjadi dua setiap 30 menit. Banyak bakteri setelah 3 jam adalah …
💬 Pembahasan 3 jam = 180 menit → n = 180 : 30 = 6 kali pembelahan.
N = 50 · 26 = 50 × 64 = 3.200 bakteri.
2Pak Dedi menabung Rp1.000.000 dengan bunga majemuk 10% per tahun. Jumlah tabungan Pak Dedi setelah 3 tahun adalah …
💬 Pembahasan M = 1.000.000 × (1 + 0,1)3 = 1.000.000 × (1,1)3.
(1,1)3 = 1,331 → M = Rp1.331.000.
3Harga sebuah motor Rp20.000.000 dan nilainya turun 10% per tahun. Nilai motor tersebut setelah 2 tahun adalah …
💬 Pembahasan Turun 10% → rasio a = 0,9.
V = 20.000.000 × (0,9)2 = 20.000.000 × 0,81 = Rp16.200.000.
4Awalnya terdapat 20 orang penderita virus flu baru. Jumlah penderita menjadi dua kali lipat setiap 4 hari. Banyak penderita setelah 16 hari adalah …
💬 Pembahasan n = 16 : 4 = 4 kali lipatan.
N = 20 · 24 = 20 × 16 = 320 orang.
5Sebuah kolam berisi 2.000 bakteri. Setiap jam jumlah bakteri menjadi 3 kali lipat. Setelah berapa jam jumlah bakteri menjadi 54.000?
💬 Pembahasan Model: 2000 · 3t = 54.000 → 3t = 27.
Karena 27 = 33, maka t = 3 jam. (Ini persamaan eksponensial bentuk 1 di dalam soal cerita!)
