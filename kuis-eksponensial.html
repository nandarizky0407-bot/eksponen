Materi 1 • Bilangan Berpangkat

Apa itu eksponensial?

📖 Definisi

Eksponensial (bilangan berpangkat) adalah bentuk an yang berarti perkalian berulang dari bilangan pokok a sebanyak pangkat n.

  • Notasi: an — a disebut bilangan pokok (basis), n disebut pangkat (eksponen).
  • Kasus penting: a1 = a, a0 = 1 (untuk a ≠ 0), dan a−n = 1/an.
  • Syarat umum soal: a > 0, a ≠ 1 — agar hasil selalu terdefinisi dan tunggal.

✨ Contoh cepat

25= 2·2·2·2·2= 32
3−2= 1/32= 1/9

Pangkat menghitung banyak faktor; pangkat negatif berarti kebalikan (reciprocal).

Intiinya: eksponensial adalah "perkalian berulang yang dikemas singkat" — begitu sifat-sifatnya dikuasai, bentuk panjang seperti 2·2·2 bisa ditulis dan dihitung sekali jalan sebagai 23 = 8.
Materi 1 • Langkah Kerja

Tiga sifat dasar yang wajib hafal!

1 Perkalian berbasis sama

am·an = am+n — pangkat saling menambah karena faktor bertambah. Contoh: 23·24 = 27 = 128.

2 Pembagian berbasis sama

am/an = am−n — pangkat saling mengurangi karena faktor saling meniadakan. Contoh: 56/54 = 52 = 25.

3 Pangkat berantai

(am)n = am·n — pangkat saling mengali. Contoh: (32)3 = 36 = 729.

✏️ Contoh: menyederhanakan bentuk campuran

(2a3b−2)2= 22·a6·b−4= 4a6b−4

Ikuti satu faktor: b−2 dipangkatkan 2 menjadi b−4 — setiap faktor di dalam kurung ikut naik pangkatnya, konstanta pun sama.

Materi 1 • Sifat-Sifat

Empat sifat lanjutan yang sering muncul di soal

a Pangkat nol & negatif

a0 = 1 dan a−n = 1/an — pangkat negatif bukan hasil negatif, melainkan kebalikan.

b Perkalian dalam kurung

(ab)n = an·bn — pangkat menembus setiap faktor, termasuk konstanta.

c Pembagian dalam kurung

(a/b)n = an/bn dan jebakan umum: (a/b)−n = (b/a)n.

d Pangkat pecahan = akar

am/n = n√(am) — pembilang menjadi pangkat, penyebut menjadi indeks akar. ⚠️ paling sering diuji!

Kasus istimewa: bila basis 0 < a < 1 (misal 1/2, 0,2), nilai an justru mengecil saat pangkat membesar: (1/2)3 = 1/8. Ini kunci pembalikan tanda di pertidaksamaan.
Materi 2 • Persamaan & Pertidaksamaan

Kapan persamaan eksponensial bisa diselesaikan?

📖 Prinsip utama

Untuk a > 0, a ≠ 1:

  • af(x) = ag(x) ⇔ f(x) = g(x) — sama-pokok, sama-pangkat;
  • af(x) > ag(x) — tanda tetap bila a > 1, tanda berbalik bila 0 < a < 1;
  • af(x) = bf(x) (a ≠ b) ⇔ f(x) = 0, karena a0 = b0 = 1;
  • Bentuk kuadrat: misalkan p = ax, selesaikan, lalu kembalikan ke x.

Satu persamaan eksponensial bisa menghasilkan beberapa persamaan sekaligus — sama seperti sistem persamaan linear biasa.

✏️ Contoh penerapan

32x−5=81 = 34
  • Samakan basis ⇒ 2x − 5 = 4
  • Selesaikan: 2x = 9 ⇒ x = 9/2
  • Pertidaksamaan: 34x−1 ≥ 33x+6 ⇒ 4x−1 ≥ 3x+6 (basis > 1, tanda tetap)
  • Jadi x ≥ 7 — cek: basis 1/2 akan membalik tanda!
Kenapa penting? 30 soal kuis hari ini memadukan sifat eksponen, persamaan, pertidaksamaan, dan soal cerita — jadi kuasai polanya: samakan basis dulu, atur tanda sesuai basis, gunakan substitusi untuk bentuk kuadrat.

Refleksi & Kesimpulan

Apa yang kita bawa pulang hari ini?

Sifat Eksponen

Persamaan

❓ Menjalankan kuis di kelas

Aplikasi ini satu file HTML mandiri. Layar tutor (halaman ini) menampilkan soal; siswa membuka halaman siswa lewat QR untuk menjawab dari HP masing-masing.

1️⃣ Host filenya agar bisa di-scan (pilih salah satu)

  • Laptop di kelas (tanpa internet): jalankan python -m http.server 8080 di folder file ini, lalu pastikan HP dan laptop satu WiFi. Buka http://IP-LAPTOP:8080/kuis-eksponensial.html — QR terisi otomatis. (Di Windows, izinkan Python pada firewall.)
  • Hosting gratis: unggah ke Netlify Drop / GitHub Pages / Vercel, buka URL publiknya, QR langsung siap.
  • Bila URL otomatis kurang tepat, ketik URL halaman siswa pada kolom di bawah QR lalu tekan Enter — QR dibuat ulang.

2️⃣ Alur kuis

  1. Siswa scan QR → tulis nama → namanya muncul sebagai "siap ✓" di daftar.
  2. Tutor menekan Mulai Kuis → soal tampil di layar dengan timer 3 menit.
  3. Siswa memilih A–E di HP-nya; chip siswa menyala saat jawaban masuk.
  4. Saat semua sudah menjawab atau waktu habis, jawaban dikunci → tutor menampilkan jawaban + pembahasan → Soal Berikutnya. Tekan Akhiri Kuis kapan saja untuk melompat ke hasil.
  5. Mengeluarkan siswa: klik tombol ✕ pada kartu nama (di lobi maupun saat kuis berjalan), lalu tekan Yakin? untuk konfirmasi. Siswa yang dikeluarkan langsung keluar dari perangkatnya, tidak bisa ikut lagi selama sesi berjalan, tetapi datanya tetap tampil di hasil akhir bertanda "🚪 dikeluarkan". Setelah kuis direset, mereka boleh bergabung kembali.
  6. Hasil tiap siswa, refleksi, dan penutup ada di slide terakhir.

3️⃣ Catatan teknis

  • Koneksi HP ↔ layar memakai WebRTC (PeerJS). Butuh internet hanya untuk "saling berkenalan" (sinyal); data jawaban mengalir langsung antar perangkat.
  • Bila ingin mencoba tanpa HP: gunakan Mode Demo (4 siswa simulasi) atau buka Mode Siswa di tab kedua pada laptop yang sama.
  • Jika QR gagal dibuat karena file dibuka langsung dari folder (file://), host dulu sesuai langkah 1, atau ketik URL secara manual.
  • Mengubah durasi per soal bisa lewat dropdown sebelum menekan Mulai (default 3 menit sesuai rencana).
